# Dados

## Estrutura

- `raw/` - Datasets brutos originais
- `processed/` - Datasets processados

## Adicionando Datasets

Coloque seus 2 datasets na pasta `raw/`:
- `dataset1/` - Primeiro dataset
- `dataset2/` - Segundo dataset

Cada dataset pode conter:
- Imagens ou arquivos de entrada
- Anotações/labels (se disponíveis)
- Metadados em JSON ou CSV

Os dados processados serão salvos em `processed/`.
